## 可直接发布的正文

做期权 Delta 动态对冲回测，真正麻烦的往往不是“跑出一条结果”，而是接下来的两个问题：

1️⃣ 参数改了以后，这次结果究竟和上次差在哪里？

2️⃣ 几种对冲触发方式放到同一段真实历史里，哪一种更值得继续验证？

DeltaLab v2.0 就围绕这两个问题，新增了 **结果对比** 和 **策略优选**。

🆚 **结果对比：把差异看清**

每次回测后都可以按需保留快照，结果自动存在本机，重开程序仍然在，最多保留 20 条。

任意勾选几条结果，就能即时对比累计曲线、期末净损益、总成本、最大回撤、触发 / 成交次数与换手额。参数差异也会直接标出，告诉你这几次回测究竟改了哪一项。

切换勾选只读缓存，不会重新跑回测。终于不用在一堆截图之间来回翻，也不用靠记忆猜差异。

🎯 **策略优选：把候选放进真实历史再筛一遍**

使用 CSV 或 Wind 真实历史，严格连续回放近周、近月、近季、近半年和近年五档周期。

每日收盘 C2C 固定作为基准；候选与基准使用相同区间、相同头寸和相同成本口径，避免“看起来在比较，实际偷换了条件”。

候选来源也不是黑盒：

- 固定间隔默认展开为 0.5σ、0.75σ、1σ、1.5σ、2σ
- 固定时刻默认使用 23:00、11:30、15:00

单一标的可按增量收益或增量信噪比排名。选中的参数可以一键写回左侧，只修改对冲策略，再回到单次回测里继续验证。

整个流程就连起来了：

**运行回测 → 保留结果 → 横向对比 → 历史优选 → 写回验证**

结果对比负责回答“发生了什么变化”，策略优选负责回答“哪个候选更值得继续研究”。

📦 Windows x86_64 和 macOS Apple Silicon 都有免安装包。模拟 / CSV 模式无需 Wind；Wind 模式需要本机已安装并登录 Wind 金融终端。

历史回测结果仅供研究参考，不构成投资建议或未来表现保证。
